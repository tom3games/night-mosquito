# 夏の夜の蚊

蚊になって、夏の夜の和室で寝ている家族の血を吸う3Dバカゲー。ブラウザで遊べる。

- 操作: スマホは左下のスティックで飛ぶ（カメラの向きへ進む）・右の羽ボタンで上下・右下で刺す。PC は WASD・Space/Shift・ドラッグ・E
- 耳元で羽音を立てると起きかけ（寝返り・寝言・しかめっつら）、起きると手・うちわ・殺虫スプレーが来る
- 朝5時に家族の「かゆみ報告書」

## 開発
- `node server.mjs` で http://localhost:5643
- `node verify.mjs` 検証一式（音は出さない）、`node sim.mjs` bot の分布、`node og.mjs` OGP 画像、`node shot.mjs <名前> <式...>` 撮影
